# Portfólio GCSI

Projeto desenvolvido para a atividade de Gerência e Configurações de Serviços de Internet, recriando o design de um card de preview de NFT e expandindo-o em uma pequena biblioteca de componentes.

## Tecnologias
- React
- Vite
- CSS

## Funcionalidades
- Card de preview de NFT com efeitos de hover
- Listagem de cards responsiva com animações de entrada
- Header do projeto com logo personalizada
